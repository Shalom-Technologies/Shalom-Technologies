# Shalom Technology Solutions — React + Vite

A polished, responsive starter website for Shalom Technology Solutions, a modern web agency serving businesses across East Africa.

## Included
- React + Vite
- React Router
- Responsive navigation
- Home, Services, Service Detail, Portfolio, About, Blog, Blog Article, Contact
- Privacy Policy and Terms of Service starter pages
- Scroll reveal animations
- CSS-only visual mockups (no image assets required)
- Placeholder phone/email
- Accessible form structure
- Reduced-motion support
- SEO-friendly title and description

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in your terminal.

## Build

```bash
npm run build
npm run preview
```

## First things to customize
1. Replace the placeholder phone number and email in `src/App.jsx`.
2. Add the final legal text to `/privacy` and `/terms`.
3. Replace concept portfolio items with real client projects when available.
4. Connect the contact form to Formspree, Resend, a custom API, or your preferred CRM/email workflow.
5. Replace the Google Fonts import in `src/styles.css` if you want self-hosted fonts.
6. Add your final domain, favicon and social preview metadata before launch.

## Design direction
The site uses a deep navy + electric blue/cyan + warm orange palette, Space Grotesk for headings and DM Sans for body copy. The design is intentionally modern/startup-oriented with restrained motion, glass-like surfaces, gradients and hover transitions.
